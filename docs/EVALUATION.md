# Independent ECC/Codex laboratory evaluation

The laboratory measures orchestration behavior only on synthetic data and code developed expressly for this purpose.

| Metric | Evidence needed | Not yet established |
|---|---|---|
| Agent role assignment | role/task trace, PR links | Yes |
| Parallel agent execution | concurrent runtime task evidence | Yes |
| Quality | tests with observed pass/fail | Yes |
| Time/cost | elapsed wall time and provider usage | Yes |
| Review independence | separate reviewer finding | Yes |
| Security | permissions and secrets scan | Yes |

Do not confuse agent catalog counts with concurrently active agent instances. Do not attribute generic Codex or GitHub Actions capabilities to ECC without observing their contribution.

CoPE's 100x target remains unchanged and independent of this lab; a synthetic task graph cannot demonstrate the compactness or functional equivalence of a conventional application.
